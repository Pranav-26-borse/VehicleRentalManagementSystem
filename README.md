# Vehicle Rental Management System

A Java Swing + MySQL based desktop application for managing vehicle rentals efficiently.

## Project Overview

The Vehicle Rental Management System is designed to manage vehicles, customers, rentals, returns, billing, payments, and reports through a simple desktop interface.

## Technologies Used

- Java
- Java Swing
- JDBC
- MySQL
- WAMP
- Eclipse IDE

## Main Features

- User Login
- Dashboard
- Vehicle Management
- Customer Management
- Rental Management
- Return and Billing
- Payment Management
- Rental Reports
- Vehicle Availability Tracking

## Database

The project uses MySQL with the following main tables:

- users
- customers
- vehicles
- rentals
- payments

The database SQL file is included in this repository.
